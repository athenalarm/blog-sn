## SIA DC-09 IP Event Reporting Protocol uye CMS kubatana

Kuti panel ikonse kutumira zviitiko zvakavimbika ku Central Monitoring Station Receiver Architecture, inofanira kushandisa protocol yakagadzirirwa IP netiweki, zvakadai ne SIA DC-09 IP Event Reporting Protocol. Kusiyana ne Contact ID yakare yakagadzirirwa PSTN, SIA DC-09 IP Event Reporting Protocol inopa data rakadzama, data encryption, ne mashoko akazara e zone ne account.

Kusawirirana kweevent format pakati pepanel nereceiver kunogona kukanganisa kushanda kwecentral monitoring. Kana panel ne receiver zvikasawirirana pamipimo ye IP packet payload, encryption keys, kana header structures, CMS inogona kurasa maseginal e alarm kana kuaratidza nedzimwe kodhi dzisiri idzo ku operator.

| Protocol / Nzira | Kutaurirana Kwakazara | Kushandiswa mu Commercial | Simba | Madomasi |
| :--- | :--- | :--- | :--- | :--- |
| Contact ID | PSTN, dialer-based | Masaiti ekare nemasanganiswa | Kuyerera kuripo mu ma receiver akawanda | Data shoma, haikodzeri zvakanaka IP-native |
| SIA DC-09 IP Event Reporting Protocol | IP / Cellular | Ma deployments e mazuva ano | Yakavakwa ye IP transport, inotsigira encryption | Inoda IP-native receiver ku CMS side |
| Proprietary IP/cellular reporting | TCP/IP, 4G/LTE | Mapurojekiti matsva e commercial | Inogona kuwedzera supervision ne data rakazara | Zvinoenderana nemhando ye magwaro ne receiver support |

## Dual-Path Network Communications Routing Resilience

Mumasitimu e aramu emagetsi ano, Dual-Path Network Communications Routing Resilience yakakosha chaizvo pakuvimbisa kuti mashoko e alarm anosvika kunotsvagwa kunyangwe kana nzira huru (primary path) yakadambuka. Masitimu anowanzo shandisa Ethernet/IP senzira yekutanga ne 4G/Cellular senzira ye backup.

Kutadza kweprimary communication path pasina supervision kunogona kukonzera kurasika kwemashoko ealarm. Dual-Path Network Communications Routing Resilience inosanganisira heartbeat signals inogara ichiedza netiweki pakati pe panel ne receiver. Kana nzira yekutanga ikasashanda mukati mechiitiko chakatarwa, sisitimu inobva yashandisa nzira yechipiri uye yozivisa CMS nezve dambudziko riya pasina kurasa kana kudzokorora zviitiko zve alarm.

| Mhando ye Saiti | Primary Path | Backup Path | Nzira ye Heartbeat | Rationale |
| :--- | :--- | :--- | :--- | :--- |
| Bazi re bhengi rine PSTN | PSTN (Contact ID) | Cellular | Test signal ye zuva nezuva | Inoenderana ne infrastructure iripo, inowedzera backup ye mazuva ano |
| Saiti idzva ye commercial | IP (DC-09 neimwe) | Cellular | Heartbeat ye nguva pfupi | IP-native saiti, cellular semushandi chaiwo we failover |
| Saiti iri kure / kumaruwa | Cellular | PSTN kana iripo | Nguva yakagadziriswa ye netiweki | Inodzivirira ma alarm ekunyepa kubva ku netiweki isina kugadzikana |
